# Barely Brewing website concept

A website concept for Barely Brewing, India's first non alcoholic craft brewery (Pune).
Designed and built by Jai Anklesaria. **Not the official Barely Brewing site.**

Single page, plain HTML/CSS/JS. Open `index.html` in a browser, or serve the folder with any static server.

- Smooth scroll: Lenis + GSAP ScrollTrigger (CDN)
- Product copy, prices and photos come from Barely Brewing's own live store; product cutouts in `img/` are made from their photos
